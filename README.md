# 📹 rtsp-webrtc-gateway

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Node.js](https://img.shields.io/badge/Node.js-18+-green.svg)](https://nodejs.org)
[![Protocol: RTSP -> Web](https://img.shields.io/badge/Protocol-RTSP%20%7C%20WebSocket-orange.svg)](https://github.com/MobileConduit)

Ultra-low-latency RTSP-to-Browser streaming bridge. Bridges corporate CCTV / surveillance cameras to browser interfaces without requiring plugin software or cloud vendor lock-in.

## 🚀 Quickstart
```bash
npm install
export RTSP_URL="rtsp://your-camera-ip:554/stream"
npm start
```
